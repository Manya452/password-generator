# 🔐 Password Generator

A modern and responsive Password Generator web application built using HTML, CSS, and JavaScript.  
This project allows users to generate strong and secure passwords with customizable options.

---

## 🚀 Live Features

✨ Generate strong random passwords  
✨ Adjustable password length  
✨ Include/exclude:
- Uppercase Letters
- Lowercase Letters
- Numbers
- Symbols

✨ One-click copy to clipboard  
✨ Responsive and clean user interface  
✨ Beginner-friendly JavaScript project

---

## ⚙️ How It Works

1. Select password length using the slider
2. Choose character types
3. Click on **Generate Password**
4. Copy the generated password instantly
